# Share links by intent: the landing boards (2026-10-19)

Kris approved SL-1 to SL-10 on board #404 (from #380's night). These are the boards of the design canvas
(https://claude.ai/artifact/49ZHvC1fjRQWBEEKWLJQ9b, private to Kris), saved as plain HTML so [O] can build SO1 to SO5
against them. Each is a phone screen, 390 x 844. Links between boards work when the folder is opened locally.

| File | Board | Decision | What it shows |
|---|---|---|---|
| `Main.html` | א, the class page (recommended) | SL-2 | Photo, class name, time, instructor, occupancy, the offer line, one button "שריינו לי מקום" |
| `OneTap.html` | ב, sign-up on the same screen | SL-2 | The form that opens as a sheet over א: name, email, terms; the code and the health declaration follow |
| `StudioFirst.html` | ג, the studio page with the class pinned | SL-1 | The studio's week, the class from the story highlighted on top |
| `FriendInvite.html` | ה, a member's invite | SL-8 | "<first name> מזמינה אותך", her class, the bring-a-friend reward; first name only |
| `InApp.html` | ו, opened inside Instagram | SL-7 | Code and password only, no Google or Face ID, the "פתיחה בדפדפן" card |
| `ClassFull.html` | ז, full or cancelled | SL-3 | The state as a chip, three upcoming sessions with room, the waitlist |
| `Booked.html` | ח, after booking | SL-10 | Confirmation, what to bring, add to calendar, send to a friend, then the home-screen offer |
| `LinkPicker.html` | ט, "where does the link lead" | SL-6 | The owner's share sheet: class, week, offer or prices, the template's default chosen |
| `Offer.html` | י, an offer link | SL-4 | What the offer includes, its end date, the first class picked on the same screen |
| `Pricing.html` | יא, the prices page | SL-5 | Offers first, punch cards with the price per class, plain Hebrew, "נרשמים כאן, ומשלמים בסטודיו" |

- Board ד ("install the app first") was rejected (#404: it can't work inside Instagram), so it is not here.
- The studio is fictional ("סטודיו נשימה", ocean accent, `noga@example.com`); the screens take the real studio's brand
  (docs/35). The names of instructors and members are made up.
- The canvas's photos are not committed to this public repository: a placeholder of the same size stands in.
- Prices and offers are sample values; the pages read the studio's listed products (SK2).
