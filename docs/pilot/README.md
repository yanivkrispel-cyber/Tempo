# ערכת הפיילוט

החומרים שמלווים סטודיו בפיילוט של Tempo: מהשיחה הראשונה ועד ההרשמה הראשונה של מתאמן.
כל הקבצים בעברית, ובלי פרטים אמיתיים: שמות, טלפונים, כתובות ומחירים מופיעים כמקום ריק בסוגריים
מרובעים, למשל [שם הסטודיו] או [מחיר לאחר הפיילוט].

| קובץ | למי | מה יש בו |
|---|---|---|
| [owner-one-pager.md](owner-one-pager.md) | בעלי הסטודיו | עמוד אחד: מה Tempo נותנת, מה הפיילוט, ומה הוא מבקש מכם |
| [pilot-offer.md](pilot-offer.md) | בעלי הסטודיו | הצעת הפיילוט: שלושה חודשים בחינם, בלי התחייבות |
| [owner-first-hour.md](owner-first-hour.md) | בעלי הסטודיו | השעה הראשונה בקונסולה, צעד אחר צעד, עד ההרשמה הראשונה |
| [member-install-guide.md](member-install-guide.md) | המתאמנים בסטודיו | הצטרפות, התקנה באייפון ובאנדרואיד, התראות, הצהרת בריאות והרשמה לשיעור |
| [faq.md](faq.md) | בעלי הסטודיו | שאלות ותשובות, אותן שמופיעות במסך "עזרה ויצירת קשר" בקונסולה |

## הערות לצוות

- הצעת הפיילוט היא ברירת המחדל עד שכריס משנה אותה. המחיר אחרי הפיילוט נשאר מקום ריק.
- התנאים המשפטיים (הסכם הפיילוט עם הסטודיו, מדיניות הפרטיות, תנאי השימוש וההצהרה) נכתבים בתיקייה
  `docs/legal`, כטיוטה לבדיקת עורך דין. עד שהם נחתמים, אין להבטיח בשמם דבר.
- שמות המסכים בערכה הם השמות שמופיעים בקונסולה ובאפליקציה. כשמסך משנה שם, מעדכנים כאן באותו שינוי.
- כמה דברים שמתוארים כאן עוד בדרך: רשימת ההכנה "מכינים את הסטודיו" בדף הבית של הקונסולה, קוד ה־QR
  וכפתור השיתוף של קישור ההצטרפות, המסך "עזרה ויצירת קשר" וייבוא יתרות הכרטיסיות מקובץ (מסומן "בקרוב").
- מה שהמוצר עוד לא עושה, ואסור להבטיח: תשלום של מתאמנים באפליקציה, ושליחת מיילים מ־Tempo
  (הזמנות וקישורים נשלחים ביד, וההתראות מגיעות לתיבת ההודעות באפליקציה ולטלפון).
